# Contributing

Thanks for helping make this a useful, evidence-led Gemini collection.

## What belongs here

Good contributions include:

- a concrete workflow another reader can reproduce;
- a prompt with the model surface and model ID recorded;
- a benchmark with a stated task set and grading method;
- a documented API or platform integration;
- a correction to a stale or overstated claim;
- a safety or failure-mode report.

## Evidence requirements

Every case should include:

- a direct source link;
- an evidence label;
- publication or observation date;
- exact model ID and surface when available;
- prompt, tool contract, test fixture, or reproduction steps;
- cost, limits, and safety boundaries when material.

Treat Arena labels, screenshots, metadata, and output style as community evidence. They are not proof of a hidden model identity.

Do not submit:

- guessed model IDs or prices;
- private transcripts or API keys;
- unpatched exploit chains or targeting instructions;
- benchmark numbers without a task definition;
- claims that a community demo is an official Google result.

## Pull request checklist

- [ ] The case has a direct source.
- [ ] The evidence label matches the source.
- [ ] The exact model ID and surface are recorded, or explicitly marked unknown.
- [ ] The prompt or reproduction method is included.
- [ ] Verification steps and limitations are stated.
- [ ] No secrets or private data are included.
- [ ] Official claims link to a Google-owned source where possible.

Use [docs/use-case-template.md](docs/use-case-template.md) for a new entry and [docs/evidence-ledger.md](docs/evidence-ledger.md) for status or source corrections.
